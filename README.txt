HĀNA — The living road
Deploy index.html, sw.js and manifest.webmanifest together to an HTTPS static host (e.g. GitHub Pages). Open URL in Safari on iPhone while online, accept location access when starting, optionally add to Home Screen, reopen online and then test with airplane mode. If location or playback fails, download a native tour app before departure. Keep screen awake, charging and foregrounded. The included synthetic audio is embedded in index.html. GPS locations are approximate and not field-tested. Do not rely on this for navigation. Manual playback is available even without GPS where the browser supports HTML audio. No network requests are needed for narration. Progress stored locally; sources are optional external links. Simulation button advances through zones. A separate HTML copy is provided; iOS Files preview may block JavaScript, so use hosted Safari copy. Never use controls while driving.
